## 🚀 Highlights (v2.7.3)

[BlueToolFixup] Resolved the AirPods "Connected but No Sound" issue for third-party Bluetooth controllers
This release introduces an opt-in Single-Gate Bypass kernel patch specifically designed to address an A2DP initialization failure when using third-party Bluetooth controllers (such as Intel).

Compatibility: Supports macOS 12.0 (Monterey) through macOS 26.0 (Tahoe).
Mechanism: The patch dynamically replaces the machine code validation sequence in the bluetoothd memory space. It bypasses the audio pipeline blockage caused by the HCI_Read_Clock failure. Devices like AirPods Pro 2 (or other Apple W1/H1/H2-equipped headphones) will now establish an A2DP audio stream instantly after connecting.

[BlueToolFixup] Fix AirDrop on some Broadcom Wireless.

### ⚙️ Usage Instructions
Since this patch intercepts a core system daemon path at the binary level, it is provided as an opt-in feature to ensure maximum system stability.
If you are experiencing the "Connected but No Sound" issue, add the following argument to your boot-args in NVRAM (e.g., via OpenCore):

Just replace the BlueToolFixup.kext

```
boot-args: -btlfxa2dpcheck
```

Reboot your system for the patch to take effect.
